# 网易云音乐扫码登录

在 ARL 的“服务连接 → 网易云音乐”保存应用凭据后，点击“扫码登录…”。二维码会显示在当前面板中。打开手机上的网易云音乐 App 扫码，在手机上确认授权，然后等待 ARL 显示结果。

- 登录会话保存后，ARL 会提示“服务调用仍待验证”。“检查登录状态”可发起一次现有的登录状态检查；不能把仅保存会话解释为所有服务调用可用。
- 网易云报告二维码过期或本次等待超时后，二维码会被移除。点击“刷新二维码”才会开始新的一次请求。
- 点击“取消操作”或关闭面板会移除二维码并取消等待。旧请求结束清理前，新请求保持不可用。ARL 不会自动创建新会话。
- 获取入口、协议校验、程序退出或本地保存失败会显示相应的有限错误提示。未知提供方结果显示为 `provider_unconfirmed`，不会显示为登录成功，也不会自动重试。

二维码是当前登录会话的敏感内容，只在本机面板内存中显示；不要转发。ARL 使用官方 CLI 返回的网易云 HTTPS 登录 URL 生成二维码，不把它当作图片地址下载，不自动打开浏览器，不记录或导出二维码内容。
