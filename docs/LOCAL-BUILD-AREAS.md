# 本机构建区

新建的可再生检查输出使用用户约定的 `~/Library/Caches/CodexBuilds.noindex/项目名-真实项目路径SHA256前12位/工具链与平台/配置/任务ID`。`script/local_build_area.py` 提供私有目录、运行期互斥锁及带来源、用途、复现命令、起止时间和状态的 manifest。调用者必须把工具的实际输出参数指向所返回目录，并回读落盘结果。

当前两类路径保留明确例外：

- 已核验的签名发布与受管安装工具强制候选位于仓库的 `build/*.noindex` 边界，ZIP 是正式交付文件，事务是恢复数据。继续保持该边界，不为迁移缓存削弱校验；暂存 App 使用 `staged_release` 生命周期管理，完成后清除。旧任务执行期间不移动其目录。
- 本地 Unix socket 夹具受 macOS 地址长度限制，现有测试明确使用短的系统临时路径；不能把完整缓存层级直接作为 socket home。测试完成后由夹具回收。日志、编译缓存和结果仍可放入新构建区。

不在可清理构建区存放已安装应用、个人数据、模型权重、运行环境或事务恢复材料。清理必须核对 manifest、锁、打开文件、Git 跟踪及近期写入；不删除仅凭名称或年龄识别的未知目录。任务结束仅保留必要的小型回执、正式交付和明确保留的失败证据。
