# 公开发布边界

2026-10-14：尚未通过公开发布验收。源码和历史存在作者环境与私有集成线索；本机签名包不等于可公开分发包。

`script/privacy_audit.py --history --output build/privacy-audit.json` 只读取 tracked 文件和可达 Git blob，不读 ignored 本地状态、Keychain、联系人、消息或笔记正文。报告只含命中类型/路径，保存在 ignored build。退出 2 表示有待核查命中，1 表示扫描失败；两者都不能宣布安全。正则扫描不是无泄漏证明，图片、二进制、资源壳与最终包还需独立检查。

本轮首轮扫描 1,537 个历史 blob。当前及历史命中：个人目录、私有应用引用、组织/隧道标识、邮箱、凭据候选。凭据候选所在测试夹具仍需人工核实，未确认真实密钥泄漏；组织与隧道标识属于已确认的私有部署线索。不要把候选计数写成已泄漏密钥，也不要把没有匹配写成安全证明。

已移除公开首页的作者路径/固定私有应用展示，协议示例改中性名称；管理面不展示未握手的配置应用。原运行状态、授权、数据与既有音乐范围保持。个人运行目录、原授权文件和既有私有配置未删除。

## 发布前必须完成

1. 将私有产品消费代码从公开运行时拆分，公开部分用通用协议和中性夹具；确需兼容的专用 identity、grant 和旧方法放在私有 composition 边界，不能随公开默认包提供。
2. 清理 tracked 文档、fixtures、脚本和资源中的私人标识；按报告逐项分类。审查图片与打包资源，不只查文本。
3. 对已识别的历史记录决定专项处理方案；若确认真实密钥，先通知 owner 并轮换，不能仅删工作树。未经专项确认不重写历史、force push 或转公开。
4. 发布无作者环境的离线依赖清单/下载器、可配置签名模板与正式 installer/updater，并在干净机器验证。
5. 确认源码与每个随包依赖的许可证/notice，核验公开归档不含 runtime 状态、日志、凭据和私有协议。

历史 audit 结果不作为新发布的豁免。发布前重新扫描全部 refs 与最终包；审查安装状态与升级恢复，而不是只看测试数量。
