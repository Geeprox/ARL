## 复现

核心与公开 CI 使用 Python 标准库。完整原生源码编译无需作者的签名、账户或私有资源壳：

```sh
python3 -B script/check_native_source.py
python3 -B script/check_review_fixes.py
```

`check_review_fixes.py` 先编译当前生产源，再链接实际 SDK、Notes、NAS 和 Control 声明执行合成测试。可用 `--native-build build/<source-check>` 复用哈希一致的 SDK；Control 策略测试重新编译当前源码。测试回执放在 ignored `build/`。

NAS Python 回归另需 `vendor/nas` 锁定的依赖。源码发行不包含本机依赖缓存；本轮使用维护者现有缓存运行这些离线测试，公开 CI 的核心组不依赖它。

完整 discovery 还包括外部消费方、私有签名资源和历史验收证据测试。因此必须同时报告其失败与公开独立回归的结果，不能把后者代替全量验收。
