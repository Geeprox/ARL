## 页面与主流程

| 页面 | 用户任务 | 简化结果 |
| --- | --- | --- |
| 概览 | 看运行状态、连接应用和待处理任务 | 应用列表集中展示，删除重复导航与信息 |
| 服务连接 | 登录账户、连接硬盘、设置权限 | 账户/硬盘/权限就近分组，按状态提供主动作 |
| 提醒事项 | 管理已授权提醒 | 保留范围、确认、结果与恢复，缩短日常文案 |
| 信息 | 在批准范围内操作信息 | 保留确认、未知结果和恢复入口 |
| 备忘 | 在批准范围内操作备忘 | 保留授权和结果核对 |
| 性能 | 排查系统用量 | 独立图表，按时间范围查看 |
| 运行记录 | 查看失败和运行事实 | 保留分页、过滤、过期/读取失败提示 |
| 诊断 | 检查模型、规则与后台 | 高级信息折叠，保留恢复入口 |

主流程：概览确认状态 → 服务连接完成所需设置 → 对应功能执行 → 核对结果。连接设置不再分散跳转；普通动作使用短名，技术事实分层。必要权限后果、失败原因和未知结果不能靠折叠或短文案抹掉。

应用卡片只由身份绑定的双向会话产生。名称、图标、版本和所需能力来自真实协议；配置、进程存在、单向发现或一次 RPC 均不能产生连接卡片。图标缺失使用通用占位，临时刷新保留原期限，到期永久退役；重连必须建立新会话。能力仍由原 policy 限定，不增加授权。
