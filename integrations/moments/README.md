# Moments local collector


## NAS refresh and incremental media

The signed native ARL owner captures immutable local SNS/WAL generations. The
Python child exports from those generations; an image CDN halt never blocks an
offline database refresh. This does not request fresh Moments from WeChat's
servers. A post absent from the Mac cache needs the official client to load it.

Friday exposes same-origin, bounded refresh and image-ID requests through the
selected SMB mailbox. It accepts no URL, file path, credentials or video request.
Visible missing photos get queue priority; requests preserve the existing
30-second interval and 120-second cooldown after each ten network requests.
Failed assets never retry automatically. Finder downloads remain paused.

New blobs are streamed without copying macOS ACLs/resource forks. Native ARL
hashes the upload and committed path before deleting a local source. Previously
committed immutable blobs can reuse the NAS-owned full SHA256 audit, matched to
the exact previous snapshot and private local receipt. Reclamation always hashes
the actual local and NAS bytes again, even when that prior proof was reused.
The NAS runtime independently hashes the complete committed media manifest after
snapshot changes. NAS rendering remains available while the Mac is offline.

Regression coverage: `ArchiveFilesTests.swift`, `AuditReuseTests.swift`, the
Python tests in `tests/Moments`, plus the Friday runtime Node tests. Runtime
`status.json` includes `nas_syncing` and bounded NAS error messages.
